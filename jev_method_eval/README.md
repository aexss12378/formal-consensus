# Jev 課本主要方法分類評估

這個資料夾用來獨立評估 Jev 能否準確分類解答使用的課本主要方法。先測量分類誤差與方法種類數的誤差，達到事先訂定的門檻後，再決定是否用於正式實驗。

目前只有評估規劃文件，尚未建立測試資料、分類程式或評估結果，也尚未呼叫 Jev API。合格門檻尚待討論，不能宣稱 Jev 已適用於這個任務。

## 分類範圍

- 方法範圍限於課本，現有方法清單位於專案根目錄的 `taxonomy.json`。
- 一份解答分類為一個主要方法；同一主要方法中的不同數學推導，不另算一種方法。
- 某方法只出現在輔助步驟時，不能只因為它被使用，就將它判為主要方法。
- Lean 驗證證明是否成立；Jev 預測主要方法。Lean 通過不能當成方法標籤正確的證據。
- 正式使用以全自動分類為目標，不設計分類不確定時轉交人工的流程；分類誤差仍須透過本評估量測。

## 測試案例

| 案例類型 | 預期分類行為 | 要檢查的錯誤 |
|---|---|---|
| 同一主要方法、不同推導 | 分到同一類 | 將同一方法拆成多種 |
| 同一題、不同主要方法 | 分到不同類，且標籤正確 | 將不同方法合併，或選錯方法 |
| 某方法只用於輔助 | 選出解答的主要方法 | 將輔助方法誤認為主要方法 |

測試資料須事先確定標準方法標籤及其判定依據。生成模型自填的標籤不能直接當成標準答案；標準答案也不能由受測的 Jev 自行產生。

同一題的多份解答須保留共同題號，才能比較方法種類數。用於調整分類說明的案例，不得再當成獨立測試結果；同一題的推導變體應放在同一資料分組，避免變體分散到調整資料與測試資料而高估表現。

## 分類輸入與輸出

預計使用 Jev 的 `Choice`，從固定的方法選項中選出主要方法。

輸入包含題目、Lean 命題、Lean 證明，以及各課本方法的判定說明。分類問題須明確要求判斷實際使用的主要方法，忽略輔助計算與同一方法內的推導差異。

不提供標準方法標籤、生成模型自填的方法標籤或生成模型身分，避免這些資訊影響分類。

輸出保留預測方法標籤、各選項機率及信心值。信心值不等於分類正確的證據，不能用它代替與標準答案的比較。

## 評估指標

| 指標 | 計算方式 |
|---|---|
| 分類正確率 | 預測方法標籤與標準標籤一致的解答數，除以受測解答總數 |
| 各案例類型的正確率 | 分別計算三類案例的分類正確率，避免整體平均掩蓋特定錯誤 |
| 方法種類數誤差 | 每題的預測標籤種類數減去標準標籤種類數；正值表示多算，負值表示少算 |
| 平均絕對種類數誤差 | 各題方法種類數誤差的絕對值取平均，避免多算與少算互相抵銷 |

方法種類數相同，不代表各份解答分類正確，因此種類數誤差與分類正確率須一起看。這裡的標準種類數只涵蓋受測解答，不表示已找出該題所有可能的課本方法。

## 正式測試前待確認

- 受測方法範圍、每個主要方法的判定標準，以及標準標籤的來源。
- 題目與解答來源、三類案例的數量，以及調整資料與測試資料的分組方式。
- 分類正確率與方法種類數誤差的合格門檻。
- 固定使用的 Jev 版本、完整分類說明與輸入格式。

以上項目須在正式測試前固定。測試結果須保留逐筆預測、標準答案、原始 API 回覆及使用設定，讓結果可以重算與檢查；資料尚未建立，因此目前沒有可執行的測試指令。
